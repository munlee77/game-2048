# Console 2048

Учебная модификация игры 2048 на C++17 с ручным перемещением плиток.
Красная клетка — курсор. Курсор перемещается клавишами `W/A/S/D` или
стрелками. Enter выбирает плитку, после чего она подсвечивается жёлтым.
Переместите красный курсор на пустую клетку или плитку с таким же числом и
ещё раз нажмите Enter. `Esc` отменяет выбор, `Q` завершает игру.

При переносе на пустую клетку плитка перемещается. При переносе на плитку с
таким же числом плитки объединяются, а счёт увеличивается. После успешного
перемещения или объединения появляется новая случайная плитка.

## Как требования выполнены

- ООП: классы `Board` и `Game` разделяют игровую модель и контроллер.
- Модули: объявления находятся в `.hpp`, реализация — в `.cpp`.
- STL: используются `std::array`, `std::vector`, `std::optional`, алгоритмы
  STL и генераторы случайных чисел.
- Внешняя библиотека: `fmt` используется для форматированного вывода поля.
- Сборка: CMake загружает и подключает `fmt` через `FetchContent`.
- Интерфейс: текстовый, работает в консоли.

## Запуск в Visual Studio

1. Откройте в Visual Studio папку, содержащую `CMakeLists.txt`.
2. Дождитесь завершения конфигурации CMake. При первом запуске требуется
   интернет, чтобы загрузить библиотеку `fmt`.
3. Выберите запускаемый объект `Console2048.exe`.
4. Нажмите `Ctrl + F5`.

Если CMake уже запускался до изменения проекта, выберите в Visual Studio
`Проект` -> `Удалить кэш и выполнить перенастройку`.
